# 🤫 GenZ Emoji Translation & Decoder Engine

An interactive, premium web interface application powered by Streamlit that acts as a translator for youth-culture emoji subtexts and double meanings. The application reads from the `genz_emojis.csv` dataset, calculating real-time usage metrics, cringe protections, and contextual advice tiers dynamically.
